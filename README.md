# E-commerce Sales Analytics Dashboard

## 1. Project Overview
An interactive three-page Power BI dashboard developed to analyse e-commerce sales performance, profitability, product categories, regional performance and customer segments.

## 2. Dataset
- 600 simulated e-commerce orders
- Data period: January–December 2025
- 18 columns covering orders, customers, products, sales, costs, profits and payment modes.

**Note:** This is a synthetic dataset created for learning and portfolio demonstration.

## 3. Tools and Technologies
- Microsoft Power BI Desktop
- Power Query
- DAX
- CSV

## 4. Dashboard Pages

### Page 1: Sales Overview
- Total Sales
- Total Orders
- Total Profit
- Total Quantity
- Average Order Value
- Monthly Sales Trend
- Regional Sales Performance
- Top 5 Products by Sales
- Interactive Region, Category and Date slicers

### Page 2: Business Insights
- Sales Performance by Category
- Profitability by Region
- Business observations
- Improvement opportunities and recommendations

### Page 3: AI-Powered Business Insights
- Decomposition Tree
- AI-assisted High Value and Low Value analysis
- Customer Segment and Product analysis
- Profitability summary
- Interactive Category slicer

## 5. Key Business Insights
- Office Supplies records the highest category sales.
- South generates the highest regional profit.
- West records the lowest regional profit.
- Improving lower-performing categories and regions could support business growth.

The objective of this project is to demonstrate practical data analytics skills by transforming raw sales data into meaningful business insights through interactive Power BI visualizations.
